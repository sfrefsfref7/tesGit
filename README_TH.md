# NIGHT MARKET DUEL — วิธีเล่นและเปิดออนไลน์ (ฟรี)

นี่เป็นเกมวางกลยุทธ์ซื้อของจัดบอร์ดแนวตลาดแฟนตาซีใหม่ ไม่ได้นำ The Bazaar มาคัดลอก โค้ดสร้างด้วย ChatGPT เท่านั้น

## วิธีเล่น
1. เปิด **ลิงก์สาธารณะ HTTPS ที่สร้างหลัง Deploy** บน iPhone หรือ Android
2. ใส่ชื่อ เลือก Hero (มี 4 ตัว) กด Create Private Room
3. ส่งรหัสห้องห้าตัวหรือกด Invite ให้เพื่อนอีกเครื่องที่อยู่ต่าง Wi-Fi / ใช้ 4G/5G
4. เพื่อนใส่ชื่อและ Join Room; ทุกคนซื้อของ จัดไอเทม 6 ช่อง แล้วกด Ready
5. ต่อสู้อัตโนมัติ Best of 3 โดยเซิร์ฟเวอร์ตัดสินทั้งหมด; หรือเลือก Challenge the AI เพื่อฝึกคนเดียว

## เปิดเซิร์ฟเวอร์ฟรี
- Upload ซอร์ส ZIP นี้ลง **repo GitHub ใหม่และแยกอิสระ**
- ใน Render สร้างบริการแบบ Web Service (Free), เชื่อม repo และ deploy ด้วยไฟล์ `render.yaml` หรือค่าจาก README.md
- ลิงก์ HTTPS ที่ Render ออกให้เป็นลิงก์ที่ส่งให้เพื่อนเน็ตนอกได้; เว็บจะใช้ WSS อัตโนมัติ
- Free instance อาจหลับเมื่อไม่ใช้งาน 15 นาที และข้อมูลห้องใน RAM จะหายเมื่อ server restart
- ต้องตรวจสอบจากมือถือบนเครือข่ายภายนอกก่อนอ้างว่าเล่นได้จริงจากเน็ตนอก

## สถานะ
- ผ่าน local pytest 32 รายการและทดสอบสอง WebSocket client จริงผ่าน localhost
- ยังไม่ตรวจ iOS/Android จริง และยังไม่ตรวจ HTTPS/WSS สาธารณะ
- ไม่ใช้ Hub / Smoodty และไม่ได้แตะเครื่อง PC ของผู้ใช้
